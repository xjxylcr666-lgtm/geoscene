# 第三方数据与素材声明

## 建筑与地震数据

纽约建筑轮廓来源NYC Open Data，保留原始来源、下载日期、查询范围和转换记录：见public/data/buildings/README.md与source.json。官方政策允许第三方使用公开数据，但不保证准确性；本项目没有把数据声明为CC0。政策：https://cityofnewyork.github.io/opendatatsm/publicpolicies.html 。人工建筑与模拟观察点不是官方数据，高度10米为假设。

USGS公开地震快照只用于旧演示；来源和查询条件见public/data/README.md。归一化距离不是地理距离。公开数据不代表任何机构为本项目背书。
