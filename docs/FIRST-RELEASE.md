# GeoScene 首版演示说明

## 项目定位

一个基于真实公开建筑轮廓的目标点可见性分析原型：Python校验输入，Three.js执行共用几何工具，DeepSeek将自然语言转成受限工具调用。支持批量目标、两方案比较、可核对结果清单和同次截图报告。
不是成熟商用巡检平台，也不以模拟数据证明客户收益或分析准确率。

## 三分钟演示

1. 打开 http://127.0.0.1:5173/inspection.html ，介绍54条纽约官方建筑轮廓、12个模拟目标、米制局部坐标；主动说明假设高度10米及平地。
2. 默认点击比较A/B：A5/12、B0/12；查看具体不可见原因和建筑ID。鼠标旋转只改变展示相机。
3. A高度2→4，展示旧结果失效；重算后首目标距离0.50→2.50米，说明输入真实影响计算。
4. 展示已经保存的 `docs/example-agent-report.html`：真实模型选择compare_observers，参数与截图来自同一次运行；同名JSON包含实际工具结果和用量。离线展示不产生模型费用。
5. 如需现场模型演示，明确启用计费开关并提交完整指令“比较方案A和B对全部巡检目标的可见性”；工具选择由模型完成，可见性由程序计算。

异常演示任选一项：不存在ID被拒绝；或缺方案时追问。当前没有多轮会话记忆，追问后重新提交完整指令，不能只回答“A”。

## 证据与状态

2026-10-08：Python64项+3子测试、Node6项、生产构建通过，共享Three.js包仍有约600KB提示。
真实DeepSeek有效比较：A高度4/B高度2，共24行，与手动结果一致；成功链路3793 tokens。
真实异常复测：未指定方案会追问，missing-target明确拒绝，均无几何结果、不可导出。提示词不是任意输入绝对保证；非法目标另有后端确定性校验。
本地服务故障、非法数值、坐标转换、孔洞、真实建筑遮挡、版本失效、工具结果字段保护有测试；不要将替身测试说成真实模型全覆盖。

## 数据与算法边界

- 来源、条款、下载查询、哈希、坐标参数见 `public/data/buildings/README.md` 和 `source.json`。
- 真实的是建筑轮廓，不是实测完整三维表面。全部高度假设10米、地形0米，观察点与目标模拟。
- 点可见性由距离、简化圆锥视角、单射线障碍检测确定；不是建筑面积可观测比，也不是导航可达性。
- 无范围外障碍、DEM、树木、精细立面与屋顶；不作为安全或测绘认证。
- 接口只绑定本机、未实现身份认证。报告输出路径目前与原本地工作目录关联，跨机器需调整。
- 旧首页的环境建筑、山湖、树木仍是装饰，不与新页面实际54个建筑障碍物混淆。

## 复现与版本管理

启动见README。先 `npm ci`，创建 `.venv` 后 `pip install -r requirements-dev.txt`。
验证：`npm test`、`npm run build`、`.\.venv\Scripts\python.exe -m pytest -q`。均不收费。
Git只用于本地留档；无远程地址，不公开发布。提交排除.env、依赖、虚拟环境、缓存和运行产物。
后续优先：确认实测高度及垂直基准、匹配地形，再完善参数对比，不优先增加多Agent或视觉装饰。
