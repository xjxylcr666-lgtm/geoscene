# GeoScene 0.1.0 首版说明

本文件是工程使用交接，不是产品收益或商业解决方案材料。安装、启动、端口和报告配置以根目录README为准。

## 已实现

54条官方建筑轮廓作为障碍物、12个模拟目标；批量分析、A/B比较、修改参数失效、非法输入提示、同次HTML/JSON报告，可选模型工具调用。
Python校验，JavaScript计算。报告默认项目outputs/inspection-reports，可配置GEOSCENE_REPORT_DIR，旧报告原位保留。

## 已验证

2026-10-08真实DeepSeek比较与手动24行一致，缺参追问、非法目标拒绝有真实样例。example-agent-report.html及同名JSON为历史证据，成功链路3793 tokens，不是本轮新模型调用。
本轮不付费调用；精确测试数量及干净目录复现范围见[验收记录](RELEASE-VERIFICATION.md)。不把测试替身称为真实模型全覆盖。

## 三分钟演示（不收费）

1. 0:00—0:30：打开http://127.0.0.1:5173/inspection.html，说明54条真实轮廓、假设10米高度、平地和模拟目标。
2. 0:30—1:10：默认比较，A5/12、B0/12；查看不可见原因，不称为整栋建筑可见比例。
3. 1:10—1:50：A的y从2改为4，旧结果清除、导出禁用；重算首目标距离0.50→2.50米。
4. 1:50—2:30：保存本次报告，核对A高度4、24行结果、版本、截图。报告为固定快照。
5. 2:30—3:00：输入missing-target，明确错误且不保留旧成功；说明模型选工具、程序计算。

## 未实现与限制

没有实测完整三维城市、DEM、机器人导航、SLAM、复杂面积比例、多轮对话、生产级认证/鉴权；没有客户收益或准确率证据。
原首页USGS归一化演示距离不是实际地理距离；装饰环境与巡检障碍物不同。
首次后台连接失败未查明根因，本轮成功不代表彻底解决。
本轮只验证本机Windows独立目录，不保证所有操作系统和依赖组合。

## 用户必须亲自掌握的5个问题

1. 如何从项目目录启动前后端？网页能打开但分析失败先检查什么？
2. 哪些数据真实、哪些是假设？为什么不能称为整栋建筑可见比例？
3. Python、浏览器JavaScript、LLM分别负责什么？普通比较是否收费？
4. 为什么改高度后旧结果失效？怎么确认重算与报告用了最新参数？
5. 默认报告保存在哪里，换目录会怎样？commit、push、部署有什么区别？

工程测试不代替用户本人解释和操作验收。
